流水線點運作？Headless 流程拆解

無需打開任何軟件，純代碼驅動的極速體驗。

📥

1. 接收模型

Web API 或文件夾監控自動獲取 STL / 3MF 檔案。

🐍

2. Python 腳本

自動識別模型特徵，動態匹配最佳層高及填充參數。

⚙️

3. Headless 切片

調用 CuraEngine 或 Slic3r 在後台靜默生成路徑。

🚀

4. 自動分發

直接推送 G-Code 至 Klipper 或 OctoPrint 開始打印。
